# Threshold — Brand Brief

**Estado**: resumen estratégico  
**Uso**: referencia rápida para futuras decisiones de producto, marca, UX/UI y comunicación.  
**Fuente maestra**: `PRODUCT_BRAND_FOUNDATION.md`

---

## 1. Qué es Threshold

Threshold es una **Personal Knowledge Platform** orientada inicialmente al aprendizaje, construida bajo un enfoque **local-first / offline-first**.

El conocimiento y el estado de trabajo del usuario permanecen operables localmente; la sincronización remota complementa la experiencia como mecanismo de convergencia, respaldo y continuidad entre dispositivos. Es un principio de producto: Threshold no debe depender de una conexión permanente para que el usuario pueda acceder y trabajar con su conocimiento.

Es un sistema personal que conecta información, contexto, documentos, notas, planificación, estudio y recuperación del conocimiento.

La universidad es el mercado inicial; no necesariamente el límite futuro del producto.

---

## 2. Qué problema resuelve

El aprendizaje moderno está fragmentado:

```
documentos + notas + fotos + calendario + LMS + mensajes + tareas
                              ↓
                      pérdida de contexto
```

El problema estructural es:

> La información está fragmentada mientras que el aprendizaje exige continuidad y contexto.

Threshold reduce esa fragmentación y evita que el usuario tenga que reconstruir constantemente dónde está cada cosa y cómo se relaciona.

---

## 3. Público objetivo

**Primario**

Estudiantes universitarios con alta carga de información, múltiples materias y necesidad constante de organizar, estudiar y recuperar contenido.

**Secundario**

- lifelong learners;
- profesionales en formación;
- autodidactas;
- personas que realizan cursos y certificaciones;
- investigadores independientes.

**No central**

Instituciones educativas, docentes y administradores.

El centro es el sistema personal del aprendiz.

---

## 4. Categoría

> Personal Knowledge Platform

**Vertical inicial**: Learning / Academic Knowledge Management

Threshold **no** es principalmente:

- una app de notas;
- un gestor de tareas;
- un calendario;
- un gestor documental;
- un LMS;
- una app de flashcards.

Es la capa que conecta esas funciones mediante contexto.

---

## 5. Propuesta de valor

> Threshold convierte información dispersa en conocimiento contextual, organizado y recuperable.

El usuario puede:

```
capturar → organizar → comprender → conectar → revisar → recordar → utilizar
```

La métrica conceptual es:

> ¿Cuánta fricción elimina entre tener información y poder utilizar el conocimiento que representa?

---

## 6. Diferenciación

La diferenciación no está en tener una feature determinada.  
Está en la **integración semántica** de las capacidades.

| Herramienta | Propósito |
|---|---|
| Drive | documentos |
| Calendar | fechas |
| Notes | apuntes |
| Tasks | pendientes |
| Anki | memoria |
| LMS | materias |
| **Threshold** | **contexto común** |

La promesa no es "tenemos más herramientas".  
Es:

> "Tus materiales forman parte de tu conocimiento."

---

## 7. Principios de producto

- El conocimiento pertenece al usuario.
- La continuidad importa más que la novedad.
- El contexto es parte del valor.
- La captura debe ser fácil.
- La IA debe asistir, no sustituir.
- Offline-first expresa autonomía y confianza.
- La complejidad debe permanecer debajo de la interfaz.
- Todo componente debe contribuir a un sistema coherente.

---

## 8. Arquitectura como expresión de la filosofía

**Local-first / offline-first**

SQLite es la fuente de verdad de la experiencia.

> Idea de producto: el conocimiento del usuario debe estar disponible y bajo su control.

**Document Domain**

Un documento no es simplemente un archivo. Es:

```
fuente → contenido extraído → modelo → experiencia de lectura
```

**StudyNote**

Representa conocimiento producido/capturado durante el aprendizaje.

Principio: la IA puede generar outputs, pero no debe apropiarse ni sobrescribir silenciosamente el contenido original.

**Reminder Engine**

Conecta:

```
conocimiento + contexto + tiempo → revisión/acción
```

## 9. Territorio conceptual de marca

**Conceptos centrales**

conocimiento · aprendizaje · contexto · continuidad · conexión · claridad · comprensión · memoria · autonomía · progreso

**Personalidad potencial**

Inteligente · sobria · cercana · profunda · confiable · progresiva

**Evitar**

- estética escolar infantil
- productividad genérica
- gamificación superficial
- dependencia visual de IA
- apariencia de panel administrativo universitario

---

## 10. Significado estratégico de "Threshold"

Threshold = **umbral**.

La interpretación conceptual más potente:

```
información → comprensión
comprensión → conocimiento
conocimiento → dominio
fragmentación → contexto
estudio → recuerdo
intención → acción
```

**Hipótesis de marca**:

> Threshold representa el punto donde la información empieza a convertirse en conocimiento utilizable.

Esto es territorio estratégico, no tagline definitivo.

---

## 11. Posicionamiento

> Para estudiantes y personas que aprenden continuamente, Threshold es una plataforma personal de conocimiento que conecta materiales, contexto, notas, planificación y revisión para reducir la fragmentación del aprendizaje.

**Promesa funcional**

> Todo tu aprendizaje, conectado por contexto.

**Promesa emocional**

> Sentir que tienes control sobre lo que estás aprendiendo.

**Principio de confianza**

> Puedes confiar en que tu conocimiento está aquí.

---

## 12. Visión

> Construir un sistema personal que acompañe a una persona durante todo su proceso de aprendizaje y convierta su información acumulada en conocimiento accesible, contextual y útil.

**Evolución posible**:

```
estudiante universitario
        ↓
gestión integral del aprendizaje
        ↓
formación profesional continua
        ↓
sistema personal de conocimiento
```

---

## 13. Guardrails para la marca

Una futura decisión de marca debería:

- reforzar la idea de plataforma de conocimiento;
- comunicar confianza y control;
- reforzar contexto y continuidad;
- funcionar más allá de la universidad;
- evitar modas visuales pasajeras;
- comunicar inteligencia sin frialdad;
- diferenciarse de una app de notas;
- convertir complejidad técnica en simplicidad de experiencia.
